# Faizan Noor Portfolio

An interactive Windows XP-inspired software engineering portfolio built with React and Vite.

## Development

```powershell
npm install
npm run dev
```

Vite serves the site at `http://localhost:5173` by default.

## Production Build

```powershell
npm run build
npm run preview
```

## Public Assets

- `public/resume.pdf` - resume displayed by the desktop PDF viewer
- `public/windows-xp-bliss.jpg` - desktop wallpaper
- `public/videos/product-scraper-demo.mp4` - product engine walkthrough
